
# GIST5300 Website

This portfolio website was created as an assignment for GIST5300 class at the University of Wyoming. It provides some information about me and my projects.

Website contains 5 pages:

Home: tells about my skills and experiences.

About: tells more about my background and shows the map of places I visited.

Portfolio: contains links to my projects in ArcGIS and Tableu mostly.

Contact: contains form to contact me.

Gallery: contains pictures that I took during my trips.



## Features

Website includes interactive elements such as buttons, menu, map with pop-ups and contact form.

It is very easy to navigate. To change page, press the button on the top of the website. There is also a button that navigate you from Home to Portfolio page.

Portfolio page contails most of the buttons. Pressing on them will navigate ypu to the new window with my project.

About page contains the map. Click on the pin to see the name and coordinates of the location.

Gallery page contains pictures and is not ineractive.
